Chrome Extension Manifest V3 DOM Interception

The Chess Bot project required a browser extension capable of reading the chess.com board state and executing moves automatically.

The Mechanics

The extension uses a Manifest V3 content.js script that runs at document_start. It periodically polls the DOM to extract the current FEN (Forsyth-Edwards Notation) string representing the board.

This FEN is then sent via fetch to a local Actix-Web Rust server. The server calculates the best move using Stockfish and returns it. The content script then simulates mouse events on the specific DOM elements representing the source and destination squares.

// Simplified DOM interaction
function executeMove(fromSquare, toSquare) {
    const fromEl = document.querySelector(`[data-square="${fromSquare}"]`);
    const toEl = document.querySelector(`[data-square="${toSquare}"]`);
    
    fromEl.dispatchEvent(new MouseEvent('mousedown', { bubbles: true }));
    toEl.dispatchEvent(new MouseEvent('mouseup', { bubbles: true }));
}

What I Took Away

Browser extensions are a unique environment. You are essentially writing code that hijacks another application’s UI. Understanding the DOM event lifecycle (mousedown vs. click) and the security restrictions of Manifest V3 (like the need for a background service worker for certain APIs) was a steep but rewarding learning curve.
